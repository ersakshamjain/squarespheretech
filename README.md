---

## 🚀 Vercel Par Host Karne Ka Tareeqa (Go Live in 2 Minutes)

Vercel par React website deploy karne ke liye aapko apne laptop par Node.js ki zaroorat nahi padti — Vercel ke cloud servers khud React ko build kar lete hain!

### Step 1: GitHub Par Code Daalein
1. [github.com](https://github.com) par ek nayi repository banayein (e.g. `squaresphere-website`).
2. Is folder ke saare files ko GitHub repo me upload ya push karein.

### Step 2: Vercel Par Connect Karein
1. [vercel.com](https://vercel.com) par login karein (GitHub se sign in karna best hai).
2. **"Add New..."** ➔ **"Project"** par click karein.
3. Apni GitHub repository (`squaresphere-website`) select karein.
4. Framework me **Vite** automatically select ho jayega.
5. **"Deploy"** button par click karein!

🎉 **1 minute ke andar aapki website live ho jayegi aur aapko free `https://squaresphere-website.vercel.app` link mil jayega!**

## 💻 Local Development (Agar Laptop par `npm run dev` chalana ho)
1. [nodejs.org](https://nodejs.org) se **Node.js LTS** installer download karke install karein.
2. Terminal me commands chalayein:
   ```bash
   npm install
   npm run dev
   ```
